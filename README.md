# GS · Good Steward

Home for the Good Steward family of products. Each product lives on its own branch of this repository so it can be cloned, run and shared on its own.

| Branch | Product | What it is | Try it |
|--------|---------|------------|--------|
| [`CGS`](https://github.com/willon-smith/GS/tree/CGS) | Commodities Good Steward | E-commerce website for a single origin coffee roastery: three bag sizes, five grind options, cart, checkout with EFT and PayFast, and a full admin panel. PHP 8 and SQLite, no build step. | [![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/willon-smith/GS/tree/CGS) |

## Working with the branches

```bash
git clone https://github.com/willon-smith/GS.git
cd GS
git checkout CGS        # the coffee website
```

Each product branch carries its own README with setup steps and hosting instructions. This `GS` branch only holds this index; new products get a new branch and a new row in the table above.
